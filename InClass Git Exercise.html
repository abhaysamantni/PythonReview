1. Login to your github account
2. Enter abhaysamantni/PythonReview in the Search or jump to box.
3. Click on the down arrow on the Fork button (top-right of the website)
4. Create a new fork. The rest of these instructions assume you created a new fork. Save it as a new repository in your github account
5. Go to command prompt
6. type git clone <paste-the-HTTPS-URL>. You can get the HTTPS URL by clicking on Code and copying the address from the HTTPS tab
7. type cd foldername to go to the folder
8. Create and switch to a new branch named after yourself (use the format firstname-lastname). You can do this in one command: git checkout -b firstname-lastname (this is equivalent to running git branch firstname-lastname followed by git checkout firstname-lastname)
9. Use a text editor of your choice to add the line "My name is <your_name> and I like <your_hobby>" to the last line in the file class_register.txt. Name should be entered in the format FirstName_LastName
10. type git add .
11. type git commit -m "Commit message"
12. type git push --set-upstream origin firstname-lastname
13. You will be asked to authenticate. On Windows the easiest option is the Git Credential Manager or the GitHub CLI (gh auth login); otherwise you can enter your login id and a personal access token. See https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens for more information
14. Go to your github account and create a pull request to request that the change from your forked repo be merged to the parent repo (abhaysamantni/PythonReview)
15. I will then receive a notification to merge your change into the parent repo
